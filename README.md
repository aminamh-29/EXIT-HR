# EXIT-HR

EXIT-HR is a simple web-based Human Resource (HR) management interface designed to streamline employee-related processes. The application provides a clean UI and responsive design for managing HR operations efficiently.

## Features

- Responsive HR dashboard interface
- Employee management UI
- Service input and form handling
- Mobile-friendly design improvements
- Simple and lightweight frontend structure
- Easy deployment on hosting platforms

## Tech Stack

- HTML5
- CSS3
- JavaScript
- VS Code
